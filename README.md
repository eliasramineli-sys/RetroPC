# RetroPC Simulator 2.0

Simulador interativo de computadores clássicos desenvolvido com HTML, CSS e JavaScript.

## Como executar

Abra `index.html` no navegador. Nenhuma instalação é necessária.

## Modos

- IBM PC: terminal RetroDOS e comandos clássicos.
- PC de 1995: ambiente gráfico inspirado no Windows 95.

## Tecnologias

HTML5, CSS3 e JavaScript, sem dependências externas.

> Projeto educativo: recriação de interfaces, não emulação integral do hardware original.
